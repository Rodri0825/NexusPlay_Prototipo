# NexusPlay — prototipo IHC

Prototipo académico de tienda digital para explorar catálogo, recomendaciones, perfil, pedidos y panel administrativo de demostración.

## Estructura

- `index.html`: estructura y contenido de la interfaz.
- `assets/css/styles.css`: estilos, colores, accesibilidad y reglas responsive.
- `assets/js/app.js`: interacciones y datos de demostración.

## Uso

Abre `index.html` en un navegador moderno. Bootstrap 5.3.8 se carga desde jsDelivr, por lo que requiere conexión a Internet para esa hoja de estilos; los estilos propios del proyecto están en `assets/css/styles.css`.

## Alcance de la demostración

Los precios, saldos y compras son ficticios. No se procesa ningún pago ni se entrega un producto comercial. No ingreses credenciales ni datos bancarios reales.
